# Security

## Reporting a vulnerability

**Please do not open a public issue for a security problem.** Report it privately through GitHub:
on this repository's **Security** tab, choose **Report a vulnerability**. Only the maintainers can
see the report.

Include what you found, how to reproduce it, which version or commit you tested, and what an
attacker could do with it. You will get an acknowledgement within a few working days, and we will
keep you updated until it is fixed. Please give us a reasonable time to release a fix before you
disclose it publicly; we are happy to credit you in the release notes.

## Supported versions

Security fixes go into the latest release. If you self-host, keep your install upgraded
(`docs/deploy.md`, "Upgrades").
